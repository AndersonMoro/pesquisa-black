Conectar ao GitHub para editar por aqui

Só precisa fazer uma vez em cada aparelho. A chave fica guardada apenas neste navegador.

  1. Abra criar chave de acesso no GitHub.
  2. Em Repository access, escolha Only select repositories e marque pesquisa-black.
  3. Em Permissions → Repository permissions → Contents, escolha Read and write.
  4. Clique em Generate token, copie e cole abaixo.

Preço = menor oferta do dia entre as lojas, segundo o Zoom. “Preço normal” é a mediana dos últimos 30 dias. Um desconto só é tratado como real quando fica abaixo disso; se o preço subiu nos últimos dias e depois “baixou”, aparece como desconto maquiado.
